答案通常在你看不见的地方——线路，以及流量怎么计费。

## 先搞懂价格差在哪：线路和计费方式

香港的带宽成本结构很特殊。本地带宽便宜，国际带宽贵，而回国直连带宽（尤其是 CN2 GIA 这类）最贵。所以「香港服务器」这四个字并不构成有效信息，你还得知道它走的是哪条路。

不同线路到大陆的延迟，量级差别相当大：

| 线路类型 | 到大陆延迟量级 | 特点 | 价格档位 |
| --- | --- | --- | --- |
| CN2 GIA | 10–30ms | 双向专线，晚高峰稳定 | 最高 |
| CN2 GT | 20–50ms | 去程 CN2、回程 163 | 中等偏高 |
| 精品 BGP / 多线 | 20–50ms | 多家运营商混合优化 | 中等 |
| 普通国际线路 | 50–150ms | 晚高峰波动明显 | 最低 |

这张表能解释很大一部分价格谜题。一个月 $6.9 的香港机器和一个月 $39.9 的香港机器，配置可能差不多，差别是后者回程走的是 CN2 GIA。

第二个容易踩的地方是流量计费。市面上主要有三种：

- 按端口：给固定带宽，不限流量，适合流量稳定的业务。
- 按流量：实际用多少算多少，适合波动大的业务，但容易月底账单惊吓。
- 超量降速：超出套餐流量后不关机，把速度压到一个较低的值继续跑。

第三种现在越来越常见。它给人的安全感其实比「不限流量」的宣称更实在——你至少知道超了会发生什么。

## 三条线路，对应三类完全不同的需求

DMIT 香港目前分三种网络方案，硬件层面的差别不大，核心区别在路由。

**Premium（HKG.Pro）**是旗舰档。电信双向 CN2 GIA，联通走 AS4837 加 AS10099，移动直连 CMI，三网回程都经香港 CTG 接国内 CN2 GIA。面向中国大陆和亚太访问优化，是这三条线里对大陆最友好的一条。测试 IP 是 103.117.100.199。

**Eyeball（HKG.EB）**是中间档。电信去程走 CN2，回程联通走 CUG 与 CMI 动态负载、移动走 CMI、电信走 163。定位是在成本和大陆访问体验之间找平衡。需要注意两点：官方仍把它标为 Beta，路由和产品结构还在调整；有第三方站点记录到这个系列一度下架，库存不稳定。测试 IP 154.12.188.3。

**Tier 1（HKG.T1）**走国际线路，接入 RETN 等国际骨干，香港到欧洲的延迟被压得比较低，但**没有针对中国大陆做任何优化**。电信用户买错这条线，延迟可能比美国机器还高。测试 IP 154.12.176.28。

一句话的选法：访客在大陆就 Pro，访客在海外就 T1，预算卡在中间且主要面向移动网络用户再看 EB。

## 价格与优惠码：先弄清哪些说法还有效

有个反直觉的点：DMIT 的年付价格基本就是月付乘以 12，年付本身不带额外折扣。比如 T1.TINY 月付 $6.9、年付 $76.9，折算下来每月约 $6.4，省了不到一美元。真正的价差来自优惠码和阶段性活动。

优惠码的时效普遍很短。2025 年 10 月曾流出一批针对香港和日本机房的循环折扣码——`202510_HKG_TYO_PRO_20OFF_RECURRING` 对应 Pro 系列季付及以上 8 折，`202510_HKG_TYO_T1_30OFF_RECURRING` 对应 T1 系列季付及以上 7 折（不含 WEE），当时官方公告写明有效期截止 2025 年 10 月 20 日。这个日期早就过去了，现在拿去用不一定还能生效。

所以正确的做法不是到处抄码，而是在结账页填进 Validate Code 框验证一次。能过就是能用，过不了就说明这轮活动已经结束，等下一轮。折扣码通常还有几个限制：只对新订单生效、不能和其他优惠叠加、不适用于特价产品。

**IP 问题。** 香港 IP 资源本来就紧。有测评提到换 IP 常见收费约 $5/次，也有「月付不保证所分配 IP 全球可用、下单时可加约 $1 购买保障」的说法。这条规则调整过，下单页上有什么选项就按什么选。

**超量行为要提前确认。** Pro 和 EB 的超量处理方式和 T1 不一样，T1 是明确降速不停机，另外两条线的规则建议在购买页核对一遍。

**退款条款。** 这次检索到的公开页面上没有明确的退款说明，如果你对试用效果没底，下单前直接开工单问一次更稳妥。

## 几个高频问题

**租香港服务器需要备案吗？**
不需要。服务器物理位置在香港，适用香港当地法律，不涉及大陆 ICP 备案流程，解析域名即可访问。但免备案不等于没有约束，内容仍需符合当地法律和服务商的使用政策。

**延迟到底是多少？**
有第三方测评转载的数据显示，香港 Premium 线路全国三网 Ping 平均约 43ms，电信、联通约 42ms，移动约 46ms，丢包接近没有。这是测评环境下的结果，不是官方承诺值，你的实际数值取决于本地运营商和时段。

**支持什么付款方式？**
支付宝、微信支付、PayPal 和国际信用卡都支持。

**能拿来建站吗？**
可以，Pro 系列的低配款跑中小型站点没问题。真要长期跑高并发的生产环境，配置往上走一档更稳，别指望 1 核 1GB 扛住流量。

**香港服务器和美国服务器怎么选？**
看访客在哪里。香港优化线路到大陆 10–40ms，美国西海岸即使走 CN2 GIA 也要 130ms 以上。访客在大陆选香港，访客在欧美选美国，代价是香港的带宽成本高得多。
